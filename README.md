# potato-wiki

개인 프로젝트, 관심 분야, 학습 기록을 Markdown으로 관리하는 Obsidian 위키입니다.

## 시작하기

1. 이 저장소를 내려받습니다.
2. Obsidian에서 저장소 루트를 **Open folder as vault**로 엽니다.
3. `00_인덱스/HOME.md`에서 시작합니다.

## 기본 원칙

- 새 메모는 먼저 `00_인덱스/INBOX.md`에 적고 나중에 정리합니다.
- 오래 유지할 지식은 `30_지식/`에 한 주제당 한 문서로 작성합니다.
- 관련 문서는 `[[위키링크]]`로 연결합니다.
- 비밀번호, 토큰, 개인정보는 저장하지 않습니다.
- 공개하면 안 되는 메모는 Git에서 제외되는 `99_비공개/`에 둡니다.

## 디렉터리

| 디렉터리 | 용도 |
| --- | --- |
| `00_인덱스/` | HOME, INBOX, 전체 문서 지도 |
| `10_프로젝트/` | 목표와 완료 조건이 있는 진행형 작업 |
| `20_영역/` | 지속적으로 관리하는 생활·업무 영역 |
| `30_지식/` | 재사용할 개념, 원칙, 학습 노트 |
| `40_자료/` | 책, 글, 영상 등의 참고 자료 정리 |
| `90_보관/` | 끝났거나 더 이상 사용하지 않는 문서 |
| `98_템플릿/` | Obsidian 문서 템플릿 |
| `99_첨부/` | 이미지와 첨부파일 |
| `99_비공개/` | 로컬 전용 메모, Git 추적 제외 |

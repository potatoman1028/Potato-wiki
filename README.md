# potato-wiki

개인 프로젝트, 관심 분야, 학습 기록을 **VS Code와 Markdown**으로 관리하는 Git 기반 위키입니다.

문서는 일반 `.md` 파일로 저장하며, Foam 확장을 사용하면 위키링크, 백링크와 문서 관계 그래프를 VS Code 안에서 확인할 수 있습니다.

## 시작하기

1. 이 저장소를 내려받습니다.
2. VS Code에서 저장소 루트를 엽니다.
3. [[VS Code Markdown 위키와 Foam 그래프 구성]]을 참고해 권장 확장을 설치합니다.
4. `00_인덱스/HOME.md`에서 시작합니다.

## 기본 원칙

- 새 메모는 먼저 `00_인덱스/INBOX.md`에 적고 나중에 정리합니다.
- 오래 유지할 지식은 `30_지식/`에 한 주제당 한 문서로 작성합니다.
- 관련 문서는 `[[위키링크]]`로 연결하고 Foam 그래프와 백링크에서 관계를 확인합니다.
- GitHub 화면에서 반드시 클릭되어야 하는 링크는 일반 Markdown 링크를 사용합니다.
- 비밀번호, 토큰, 개인정보는 저장하지 않습니다.
- 공개하면 안 되는 메모는 Git에서 제외되는 `99_비공개/`에 둡니다.

## 권장 VS Code 구성

- Markdown All in One
- markdownlint
- Markdown Preview GitHub Styling
- Markdown Preview Mermaid Support
- Foam

설치와 설정 방법은 [[VS Code Markdown 위키와 Foam 그래프 구성]]에서 확인합니다.

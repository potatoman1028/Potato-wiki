## 자동 지식 목록

아래 목록은 VS Code의 Markdown 미리보기에서 Foam이 자동으로 생성합니다. `type: 지식` 문서를 추가하면 별도로 이 목록을 수정하지 않아도 됩니다.

```foam-query
filter:
  type: "지식"
select:
  - title
  - tags
  - field: properties.updated
    label: 수정일
sort: properties.updated DESC
format: table
limit: 200
```

## 저장된 쿼리

- 태그 없는 지식
- 연결 점검
